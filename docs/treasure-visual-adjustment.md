# 宝箱・宝石の演出調整

2026-10-12。GitHub main の 0409f35 を基準に調整。

既存の聖域の背景、深い紺色、古金色、明朝体に統一しました。宝箱は紺色の面と金属の縁、細い装飾、淡い紫の封印で構成。宝石は多面体の結晶にし、未取得の枠は控えめに表示します。

装備が次々に切り替わる表示を取り除き、約2.6秒の静かな発光から宝箱が開き、装備が現れる流れにしました。跳ねる動き、激しい揺れ、大きな粒子、強い光を抑えています。発見時の見出しも画面全体と調子をそろえました。

抽選確率、9個の宝石による保証、装備発見後の宝石リセット、重複素材、学習記録の処理は変更していません。core.js と gear.js は基準版と同一です。

## 検証

- core / gear：79件成功。
- Chrome：通常発見、宝石獲得、9個到達、9個の献上、重複素材、スキップ、スマートフォン、動きを減らす設定を検証。
- 実際に計算を5問正解し、日課達成から宝箱・宝石獲得まで確認。
- スキップ時を含め、装備箱の消費と発見回数の保存が1回のみであること、再読み込み後も維持されることを確認。
- 装備と見出しの重なり、横方向のはみ出し、スマートフォンでの「続ける」の表示位置を確認。

実行：`node --test app/tests/core.test.cjs app/tests/gear.test.cjs` と `node app/tests/treasure-presentation-browser.test.cjs`。

画面画像は `app/reports/treasure-screenshots/` に保存。
