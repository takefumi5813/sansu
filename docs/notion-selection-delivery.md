# Notion基準の問題選定と反映

今回の選定一次資料はNotionの問題・型・教材回データ。Notion・sources・Dropbox元資料は読み取りのみ。第25〜27回はユーザー指定の未習範囲として今回の出題設定と残件から除外した。

|図形|1|1|Notion R24T⑥-1(5)。直近復習のみ。以前のPDF直接選定3問は保管|

合計49問。計算は標準7・応用14・難問6。一行の追加18問はNotionの型基礎難度＋上乗せにより標準17・応用1・難問0。収録数のために難度を引き上げたり問題を創作したりしていない。

Notionの型名は粗い分類もあるため、同じ型IDでも必要な逆算・条件処理が異なる場合は別の習得単位に分けた。既存一行3型も時間の算出、既知速度を引く逆算、同方向の周回差という判断差により維持。

一行R24H④-5だけはNotion本文が数値替えの略記なので、同じNotionレコードを採用したうえで原本の同一問題から全文を補完し区別記録した。R24H⑥-2はNotionと原本が一致し、ローカル略記のA/B誤りを採用していない。Notionの解き筋に元Nの数値が残るものは転用せず、独立して解説を制作・検算した。

範囲初期値は直近R24・次回グノレブ既習部分R24。試験日11/11と元の4回範囲は既存設定由来で、Notionに試験範囲項目はない。未習除外はユーザー指定が根拠。家庭学習H限定は原依頼の明示要件。教材回のNotion同定とは根拠を分けている。

検証：基礎/装備79項目、計算29項目、一行18正答/18途中確認、図形座標検算。実Chromeで旧設定の移行、計算5問任務、一行2型任務、自由遠征の解放判定、図形の誤答後の途中確認、390px表示を確認。別エージェントの独立レビューでも重大な不整合は見つからなかった。

選定時点では外部変更を行っていない。今回、選定方針と教材解説をNotionの算数ページへ追記し、オープニングを加えたアプリを既存GitHubリポジトリへ反映する。
