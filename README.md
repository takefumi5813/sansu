# 算数クロニクル

「冒険に進む」から入る算数一問一答。計算・一行問題・図形の学びで装備を鍛え、英雄を召喚します。

公開画面はルートの index.html。学習記録は利用端末のブラウザーに保存されます。

今回の教材はNotionを基準に選定した49問（計算27・一行21・図形1）。復習と次回グノレブ対策は既習の第24回を対象とし、第25〜27回は含めません。選定の詳細は docs/ を参照してください。

## 開発

ソース・教材は app/ にあります。

```text
node app/build.cjs
node --test app/tests/core.test.cjs app/tests/gear.test.cjs app/tests/selected-calc.test.cjs
node app/tests/selected-oneline-validation.cjs
node app/tests/selected-geometry-validation.cjs
```

ビルド結果は app/dist/。配信時は index.html と assets/、figs/ をルートへコピーします。ブラウザー検証は開発環境のPlaywrightとChromeのパスを指定します。教材再選定スクリプトはローカル保管のNotionスナップショットを必要とします。個人の学習履歴・誤答ログ・Notionの生スナップショットはこのリポジトリに含めません。

## 細分類×難易度の出題とNotionへの一本化（2026-10-24）

分類の正本をNotion問題DBの「細分類」（大分類→中分類→細分類）に一本化し、別系統だったB57（コベツバPoint由来の枝443）を廃止しました。B57の照合結果は、Notion側の細分類の見直し（244問を照合し68問の主細分類を修正）に使いました。

- ビルド時に `app/content/notion-classification.json`（Notionの書き出し）を読み、各問題に細分類・出題区分（代表／類題／数値替え）・難易度を付けます。難易度はNotionの「細分類の基礎難度＋上乗せ」。小問ごとの見直し（difficulty-reviews）と個別キュレーションはそれより優先します。
- 通常の出題（修練の砦・決戦の門・自由遠征）は「代表」だけ。自由遠征では中分類→細分類をえらぶと、その解き筋の代表を難易度帯で出します。
- 正解後の「同じ解き筋の類題」「一段上の類題に挑戦」は、同じ細分類の問題（代表・類題ポットの両方）から、同じ難易度帯／一段上の帯を出します（以前の手張りリンク59本ではなく細分類で決まる）。
- 新しい遠征先「類題の書庫」は類題ポット（代表以外）から出します。アプリ用の解説・採点データがある類題がまだほぼないため、現在は「準備中」表示です。
- 学習記録のキー（unitId）は変えていないので、端末の記録・復習予定はそのまま引き継がれます。
- B57の品質保留1問は `app/content/quality-holds.json` に引き継ぎ、出題しません。B57の一覧画面・カタログは削除しました。
