# 算数クロニクル — 英雄と叡智の試練

「冒険に進む」のオープニングから入る、英雄召喚と装備の発見・鍛錬を中心にした算数アプリです。Notionを基準に問題を選び、計算・一行問題・図形を収録しています。

## 開き方

`dist/index.html` をChromeで開きます。すでに開いている場合は再読み込みしてください。ZIPは全体を展開し、`dist/assets` と `dist/figs` を同じ位置に置いてください。公開サーバーやAPIキーは不要です。

学習記録はブラウザー内のIndexedDBに保存します。同じブラウザー・同じ場所・同じ開き方で使ってください。「記録と設定」でバックアップを書出・読込できます。ファイル直開きとHTTPのURLは別保存領域です。

## 修練と遠征先

計算・一行問題・図形の3分類です。一行問題と図形は次の3範囲から選びます。

|画面の名称|出題範囲|解放条件|
|---|---|---|
|修練の砦|復習テスト対策：直近授業の範囲のみ|いつでも選択可|
|決戦の門|次回グノレブの範囲のみ|いつでも選択可|
|自由遠征|全分野|前2範囲で今日取り組む問題が、選んでいる分類（一行問題・図形それぞれ）で0になったとき|

「残り」は未着手、復習期限到来、修復期限到来の習得単位です。期限が未来の問題と卒業済み問題は含みません。難易度や分野で隠した問題も解放判定では残件に数えます。同型の問題は1つの習得単位です。

両範囲は「記録と設定」で別々に指定します。今回の直近授業はR24、次回グノレブ対策も既習のR24だけです。R25〜27はユーザー指定の未習範囲として除外し、追加待ち・残件に含めません。以前の試作用R20初期値と未習範囲の設定を初回移行します。次回グノレブは原依頼に従い家庭学習Hのみ。復習対策ではR24Tの独立した図形小問も対象とします。試験日11/11は既存設定の参考値で、Notionには試験範囲・授業日の項目がありません。

難易度は一行・図形では「基礎／標準／応用／難問」。D1〜2／D3〜4／D5〜6／D7〜10の排他的な区分です（旧「標準」D1〜4を基礎と標準に分割）。計算も同じ「基礎／標準／応用／難問」ですが、式の形で分けます（core.calcTier）。基礎＝計算1〜2回でそろった数どうし（整数・簡単な小数の加減、□を1回で求める逆算など）／標準＝計算3回以上、分数・小数の掛け算割り算、答えが割り切れない、逆算が2回以上／応用＝逆算＋分数、逆算＋小数の3回以上、掛け算割り算をふくむ5回以上の逆算、括弧つきの5回以上、分数・小数のまじった長い掛け算割り算／難問＝括弧と分数（2か所以上）と多くの四則がそろった逆算（例：(15/7+0.6)×□+6と7/13−19/91＝9）や、括弧を重ねた分数・小数の長い計算。現在の計算は基礎35／標準167／応用66／難問18問です。報酬の経験値は従来の★1〜3のままで、逆算は区分から★を決めます（基礎・標準＝★1、応用＝★2、難問＝★3）。5年生の上限D8は維持。

## 報酬とデイリー

|修練|クリア報酬|デイリー任務|達成報酬|
|---|---|---|---|
|計算|鍛造素材1|異なる計算を5問|素材5＋10%の装備箱抽選|
|一行問題・図形|英雄の魂1|両分類合計2型|魂2|

独力正解、または誤答・補助利用後の解説チェックポイント通過でクリアになります。チェックポイントでは段階経験値は得られません。計算は回数制限なく「次の計算へ」で続けられます。同じ式への経験値・素材付与は当日1回。計算の1日2問経験値上限は撤廃しました。

計算の任務達成時は宝箱の演出が入ります。「宝箱を開ける」で抽選演出を行い、当たりならその場で装備箱を開けて装備を発見します。外れは宝石1個（連続外れ回数＝宝石の数、最大9個）として表示し、9個そろうと次の宝箱で宝石が捧げられて必ず発見します。途中で当たると宝石は消えます。初期装備は「旅立ちの短剣」1本です。装備箱1個で全12種から均等に抽選します。短剣も抽選対象で、重複は素材3個に還元。計算の任務達成時に1回だけ10%で箱を抽選し、9回連続で外れた次の任務達成は当選を保証します。当選後は連続回数が0に戻ります。箱の抽選回数は、任務未達の日には増えません。

装備の発見と鍛錬を分けています。所有装備は名前・種類を保ったままLv.1〜10へ育ち、次のレベルと同じ数の素材（2〜10個、合計54個）が必要です。装備戦力は品質×10＋(鍛錬Lv−1)×3。現行12種はすべて品質1で、学習分野とは結びつけません。3つまで装着でき、以前の40種の所持品は保管庫に残して着脱できます。以前の装備は新しい抽選・鍛錬の対象にはしません。

英雄1人の召喚に必要な魂は、召喚した回数に応じて3個から15個まで段階的に増えます（1〜3回目は3個、以後3回ごとに1個増え、37回目以降は15個）。1人を同行させます。通常召喚の50人が最初から各1/50（2%）の均等確率で登場し、レア度・レベル・所持状況・召喚回数で確率は変わりません。重複時は魂の返却なしで「契約の証」を1個獲得。共通の証が貯まると（交換に必要な個数は、交換した回数に応じて3個から15個まで段階的に増えます。1〜3回目は3個、以後3回ごとに1個増え、37回目以降は15個）、ランダムな未所持英雄の最大3候補から1人を選んで交換できます。候補は再表示・再読込で変わらず、交換後に更新します。交換・重複で絆は増やしません。Lv900は別の経験値曲線による成長の目安です。経験値倍率は付けていません。

自由遠征の一行問題・図形を独力正解すると、同行英雄の絆が＋1。同型は当日1回までです。絆Lv.1〜10の累計正解数は0・3・8・15・25・40・60・85・115・150。最高レベルは英雄1人につき150問です。旧300問版の有効な絆値は150で上限処理し、旧版の重複召喚の記録からは換算しません。

練習・数値替えでは通貨、経験値、日課、習得段階は増えません。計算は基礎から難問までのどの区分でも5問の任務に取り組めます。

## 復習と記録

独力正解後14日・60日・180日を空けて確認し、4段階目は考え方のチェックポイントも必須です。誤答・補助利用は1段階戻して3日後に修復。同じ段階の経験値は再獲得しません。優先範囲を消化するため週2型の新規制限を撤廃。自由遠征には継続中60型・7日以内の復習5型の負担上限を残しています。

レベルは floor(900 − 899 × exp(−XP/1500)) を基本に、12,000ptで900に到達します。旧XP、履歴、筆跡、所持英雄・装備、星の記録は保持。新通貨は0から始め、遡及付与や星の変換はしません。

ペン入力は線を逐次描画し、ペン使用中・直後の手のひら（指）の接触は描画・スクロール・ボタン操作に使いません。ペンを検出すると「指でも書く」を自動で切ります。ペン使用後の下書き欄の移動は2本指で行います。ペン・色・太さ・消しゴム・取り消し・ボタン拡大・指移動、原図への記入、当日未解答の再開に対応。保存失敗時は未保存を表示し、メモリの記録を書き出せます。手書きは端末保存、固定ヒントと段階解説に対応していますが、筆跡や途中式をAIで解析して個別に指摘する機能は未実装です。

## 画面と教材の根拠

既存算数と国語・社会・理科indexを参照。既存の英雄肖像50点を保持し、追加英雄7人の肖像を制作しました。理科アプリと重複する科学者7人は新規召喚・交換候補から外し、既存の所持・同行・絆は保持します。通常召喚の50人は未所持時に本人の輪郭を使った匿名シルエットで表示します。装備12種と、英雄の魂・鍛造素材のアイコンには新規生成画像を使用します。深い紺を背景に、金を装備、紫を英雄の魂に対応させ、問題と手書き面は明るく保っています。

問題の選定一次資料はNotion問題DBです。計算はR24K全50問から17問を採用し、標準計算5問を既習のR23/R21から補充。既存計算5問もNotionで再照合しました。一行問題はR24Hを必要な判断ごとに分け、同じ考え方の問題は代表にまとめます。図形はNotionのR24T⑥-1(5)を選び、原図をPDFと照合しました。以前のPDF直接選定による必勝手筋3問はデータを保管し、今回の配信から外しています。Notionの問題データは維持し、「算数」ページに今回の選定方針・採用問題・段階解説を追記しました。

今回の採否と根拠は reports/r24-calc-selection.md、r24-oneline-selection.md、scope-selection.md、content/selected-geometry.json にあります。取得したNotion情報のスナップショットもローカルに保存しています。
